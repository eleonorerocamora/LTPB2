Exporter les prix vers le code (HARDCODED_DEFAULT_PRICES)

Important : les prix que tu as saisis sur les pages ne sont pas dans les fichiers .html sur le disque — ils sont dans le navigateur (localStorage).

Pour les récupérer :

  1. Lance un petit serveur local dans le dossier du site :
    cd "/Users/ele/Documents/site LTPB html" && python3 -m http.server 8765
  2. Ouvre http://localhost:8765/, va sur chaque catégorie où tu as déjà mis les prix (même origine = même localStorage).
  3. Reviens sur cette page http://localhost:8765/export-prix.html et clique sur « Générer le code ».
  4. Copie chaque bloc ci-dessous et remplace const HARDCODED_DEFAULT_PRICES = {}; dans le fichier .html correspondant.
